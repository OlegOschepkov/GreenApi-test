# Telegram + GREEN-API

Веб-интерфейс для отправки и получения сообщений в мессенджере Telegram
через GREEN-API. Минимальный сценарий: реквизиты GREEN-API → поиск чата
по номеру телефона → отправка текста → получение ответа.

## Возможности
- Подключение по idInstance + apiTokenInstance, проверка через GetStateInstance
- Поиск чата по номеру телефона и загрузка истории (50 сообщений)
- Отправка текстовых сообщений 
- Тёмная тема по значениям с web.max.ru

## Требования
Node.js 22.12+, npm. Аккаунт GREEN-API с созданным инстансом.

## Настройка
1. npm install
2. Создать .env:  VITE_GREEN_API_URL=********
   (адрес из личного кабинета, у каждого инстанса свой)
3. npm run dev

## Настройка инстанса в кабинете GREEN-API (ВАЖНО!)
- Включить галочки уведомлений (входящие, исходящие)
- webhookUrl оставить пустым: приложение использует HTTP API, а не вебхуки
- Без включённых галочек очередь пуста и входящие не приходят

## Команды
dev / build / preview / check / lint / lint:styles / format

## Безопасность
Реквизиты хранятся в localStorage браузера. Токен уходит в адресе
запроса — не используйте на общем компьютере! Выход удаляет данные.

## Ограничения
- Только текстовые сообщения
- Только российские номера (+7)
- Один открытый чат за раз, список чатов не загружается
